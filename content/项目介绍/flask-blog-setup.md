Flask 是一个轻量级的 Python Web 框架，非常适合用来搭建个人博客。它不强制你使用特定的项目结构，让你可以从一个单文件应用开始，逐步扩展成完整的站点。

本文将带你走完从零到可访问首页的全过程，包括虚拟环境、目录规划、模板继承，以及如何让页面在深色主题下保持舒适的阅读体验。

## 为什么选择 Flask

对于个人博客来说，你往往不需要 Django 那样全套的 ORM、Admin 后台和用户系统。Flask 提供了路由、模板渲染和静态文件服务这些核心能力，其余部分可以按需引入。

> 好的工具应该在你需要时出现，在你不需要时保持安静。Flask 正是这样一种框架。

### 核心优势

- 学习曲线平缓，文档清晰
- 与 Jinja2 模板引擎无缝集成
- 静态资源管理简单直观
- 部署灵活，从本地开发到云服务器都适用

## 项目结构

推荐采用应用工厂模式，将配置、路由和模板分离。一个典型的起步结构如下：

```
first_blog/
├── app/
│   ├── __init__.py      # 应用工厂
│   ├── routes.py        # 路由定义
│   ├── posts.py         # 文章数据
│   ├── static/
│   │   ├── css/
│   │   └── js/
│   └── templates/
│       ├── base.html
│       ├── index.html
│       └── post.html
├── requirements.txt
└── run.py
```

### 创建虚拟环境

使用 Conda 或 venv 隔离项目依赖，避免污染全局 Python 环境：

```
conda create -n blog python=3.11
conda activate blog
pip install flask
```

## 模板继承

通过 `base.html` 定义站点的公共骨架——页头、页脚和全局样式。子模板使用 `{% extends %}` 和 `{% block %}` 填充各自的内容区域，避免重复代码。

首页展示文章列表，详情页则专注于沉浸式阅读：单栏居中、合适的行高、清晰的标题层级，以及适配深色主题的代码块。这些细节决定了读者愿不愿意读完一篇文章。

> 排版不是装饰，而是让内容本身更容易被理解的工具。

## 下一步

当静态页面跑通之后，你可以逐步引入 Markdown 渲染、数据库存储、RSS 订阅，以及全文搜索。但第一步永远是：让一个页面正确地显示出来。
