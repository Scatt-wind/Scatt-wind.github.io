## 今天，编程圈又地震了

打开社区，满屏都是哀嚎。

Claude Code 今天又双叒叕大面积封号了。和以往不同，这次不是小打小闹——国内用户几乎被一锅端，稳定用了一年的老号说没就没，甚至有百人规模的公司直接被团灭。一封来自 Anthropic 安全团队的邮件，措辞冰冷而简短：

> *"我们对你账号的可疑信号进行了内部调查，认定存在违反使用政策的行为。因此，我们已撤销你访问 Claude 的权限。"*

没有具体违规条款，没有任何事先警告。一众天才程序员，就此「陨落」。

## 更劲爆的：代码里藏了"木马"

如果只是封号，大家可能也就认了——毕竟用别人的服务，人在屋檐下不得不低头。但这次不一样，社区里有人把 Claude Code 逆向了，扒出来的东西让所有人脊背发凉。

Reddit 用户 @LegitMichel777 在逆向 Claude Code 2.1.196 版本时，意外发现从 **2026 年 4 月 2 日的 2.1.91 版本** 起，Anthropic 就已经悄悄内置了一套隐蔽的检测机制，而且从未写入官方更新日志。这套机制干了什么呢？

**第一，读你的系统时区。** 检测是否设置为 `Asia/Shanghai`（上海）或 `Asia/Urumqi`（乌鲁木齐），精准定位中国用户。

**第二，扫你的网络环境。** 维护了一份包含 **147 个条目** 的域名黑名单，涵盖百度、阿里巴巴、字节跳动、蚂蚁集团、快手、小红书、京东、哔哩哔哩、月之暗面、MiniMax、阶跃星辰等中国科技公司及 AI 实验室的域名，以及大量 Claude API 中转服务地址。

**第三，也是最阴的——用隐写术传递检测结果。** 它不会直接发一个 `isChineseUser: true` 给服务器（那太容易被抓包了），而是通过修改系统提示词中的**肉眼不可见的 Unicode 字符**来打标记。比如，用不同编码的"单引号"来标记你是否使用了中国域名，用日期格式中的连字符（`-`）和斜杠（`/`）来标记你的时区。服务端只需检查一下这些字符的 Unicode 编码，就能秒判你是不是中国用户。

说白了，**一个拥有你代码仓库和命令执行权限的 AI 代理，在背地里给你做用户画像，而你完全不知情，也完全无法关闭这个功能。**

Claude Code 团队的 Thariq 今天已经在 X 平台公开承认了这件事，表示"将在明天更新中删除相关代码"。但说实话，信任一旦崩塌，哪是一句"明天就删"能修复的？

这已经不是 Anthropic 第一次搞小动作了——之前就被曝出在用户通知邮件里安装追踪器。用网友的话说：*我不光没有底线，我还没有下限。*

## Codex？门槛太高，Bug 太多

有人说，那换 OpenAI 的 Codex 呗？

说实话，Codex 我认真试过一段时间，体验只能用一个字概括：**累**。

- **网络封锁**：`api.openai.com` 国内无法直连，需要特殊的网络环境，稳定性全靠缘分。地铁里、出差途中基本就是废铁。
- **使用成本高**：官方 Plus 订阅 20 美元/月，跨境支付也是麻烦事。Token 按量计费，做大型项目重构时费用直接起飞。
- **Bug 频出**：2026 年至少发生了 7 起独立的可靠性事故。6 月 15-16 日还来了一次大宕机，核心原因是 GPT 5.5 的速率限制饱和。还有著名的 #19215「幻象限额」Bug——明明额度充足，系统非说你用完了。
- **风控越来越严**：6 月份也搞了两波封禁，200 刀的账号没有任何预警直接封停。登录环节还加了强制手机号验证，明显是针对共享账号和跨区使用。

用一个编程工具，搞得跟做地下工作一样，身心俱疲。

## 思来想去，还是国产全家桶香

折腾了一大圈，我最终还是回到了阿里百炼的全家桶：**通义千问 + Qoder + QoderWork**。

为什么？原因很简单：

**✅ 国内无痛使用。** 不需要梯子，不需要折腾网络，不需要担心被封号。注册即用，打开就写，真正的开箱即用。

**✅ 成本低到离谱。** 百炼平台的 API 调用价格，相比 Claude 和 Codex 简直是白菜价。个人开发者和中小团队完全负担得起，再也不用盯着 Token 消耗提心吊胆。

**✅ 生态完整。** 千问负责对话和推理，Qoder 负责代码生成和智能编程，QoderWork 负责工作流自动化和任务编排——三件套覆盖了从写代码到部署运维的全链路。

**✅ 不用担心被"背刺"。** 自己的平台，自己的数据，自己的代码。不会有人在你电脑里种木马，不会有人悄悄给你的请求打标记，更不会突然一封邮件把你的工作流全部中断。

## 80%的场景，真的够用了

我知道有人会说：可是排行榜上，Claude 和 GPT 的分数确实比千问高啊。

没错，这一点我不否认。但冷静想想：**我们日常 80% 的编程场景——写 CRUD、做业务逻辑、调接口、写单元测试、做代码审查、写文档——千问完全够用。** 真正需要顶级推理能力的复杂架构设计和跨文件重构，确实还有差距，但这个差距在肉眼可见地缩小。

而且中国的 AI 发展一直在紧跟美国的脚步。从通义千问到 DeepSeek，从月之暗面到智谱，国产大模型的进步速度有目共睹。今天我们在某些维度可能还差一截，但按照这个速度，相信不会让我们失望太久。

更重要的是——**一个随时可能被关停的工具，哪怕再强，也不是真正属于你的生产力。**

## 写在最后

今天的封号事件，与其说是一次技术事故，不如说是给所有中国开发者敲响的一记警钟：

**核心技术，终究要握在自己手里。**

与其每天提心吊胆地用别人的工具，不如踏踏实实拥抱国产生态。不是因为"爱国情怀"，而是因为——**稳定、可控、可持续，才是一个工程师选择工具时最该看重的东西。**

好了，不说了，我去 Qoder 里把今天的项目写完。🫡
